How far to trust it

The lens is a borrowed ruler. Every depth is read through the final norm and the output head, which were trained on the last depth only. A flat or reversed curve early on says this one direction does not separate the rows there, not that the residual could not.

The lean and the mass are different questions. The lean is a difference of two logits, so the softmax normaliser cancels and it means the same thing at any mass. The mass says whether the head would emit a verdict word. Only an argmax inside the set is poisoned by low mass, so none is computed.

The slot follows the model's own fields. Each row is prefilled with the fields the daemon generated before this slot, in the order it generated them, so the curves show this value being read off those fields as much as off the command. At the first closed-choice slot there is only the free-text effect sentence in front of it.

Examiner, not daemon. Groups come from the daemon's token-by-token decode; curves come from a cold chunked prefill of the same bytes. In "every row" those rows are drawn dashed.
